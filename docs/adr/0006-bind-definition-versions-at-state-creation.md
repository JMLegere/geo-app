# Bind immutable definition versions when durable state is created

EarthNova authored content uses stable identities with immutable versions, while durable player state persists the exact version that produced it. An Encounter references the exact Encounter Definition Version under which it occurs. Generate Item Outcomes reference stable Base Item identities, bind the current published Base Item Version when each Item is created, and persist that resolved Version on both the Item and applied Outcome result; delayed Identification uses the Item’s bound Version, while Discovery and Index remain keyed to the stable Base Item identity. We reject mutable latest-version lookup after state creation, flattening complete definitions into every occurrence or Item, and transitive version pinning that would force cascading content republication; newly published versions affect future state creation only.
