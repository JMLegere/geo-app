# Centralize visual code in an in-app UI layer

EarthNova centralizes all visual widget code, including screens and feature-specific widgets, under `lib/ui/design_system/` for foundations and reusable components and `lib/ui/product_surfaces/` for domain-grouped product UI; the app and Widgetbook consume the same production implementations. This supersedes only [ADR 0005](0005-domain-oriented-vertical-slices.md)'s feature-owned UI rule: feature slices retain providers, application logic, domain models, and data access, while the UI layer depends on them and reusable design-system components remain independent of feature internals. We accept reduced vertical-slice UI locality to give the complete visual system one code ownership boundary without pretending product-specific screens are reusable components; this approved target architecture does not authorize implementation or deployment.
